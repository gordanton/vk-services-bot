# ИИ-бот сообщества ВКонтакте для приёма заявок и консультаций (`vk-services-bot`)

Чат-бот для сообщества ВКонтакте на базе **vkbottle (LongPoll)** с интерактивным меню услуг, приёмом заявок и отзывов и встроенным ИИ-консультантом.

## Цель и задачи проекта

- **Цель:** Автоматизировать первичную обработку обращений клиентов в группе ВКонтакте: отвечать на вопросы по услугам 24/7, собирать заявки (лиды) и передавать их администратору.
- **Ключевые задачи:**
  - реализовать удобную навигацию по карточкам услуг с клавиатурами ВКонтакте;
  - настроить пошаговый сценарий (FSM) сбора контактов клиента и сохранения заявок;
  - подключить языковые модели через OpenAI-совместимый API с сохранением истории диалога;
  - упаковать бота в Docker-контейнер для работы на сервере без открытия входящих портов.

## Результаты

- Бот самостоятельно консультирует посетителей сообщества по прайсу и условиям услуг, опираясь на системный промт с актуальным каталогом.
- Все заявки и отзывы мгновенно пересылаются администратору в личные сообщения ВКонтакте и дублируются в локальное хранилище `leads.jsonl` (Docker volume `bot-data`).
- Работа по протоколу LongPoll позволяет запускать бота на любом VPS без настройки SSL-сертификатов и вебхуков.

## Использованные технологии и библиотеки

- **Язык:** Python 3.11+
- **Фреймворк VK API:** `vkbottle` (асинхронный LongPoll, FSM-состояния, клавиатуры)
- **ИИ и сетевые запросы:** `httpx` / OpenAI-совместимый API (`ProxyAPI`), `python-dotenv`
- **Инфраструктура:** `Docker`, `Docker Compose`

## Локальный запуск

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

Скопируйте `EnvExample` в `.env`, заполните ключи (`VK_TOKEN`, `PROXYAPI_KEY`, `ADMIN_ID`) и запустите:

```bash
python bot.py
```

## Запуск в Docker на сервере

```bash
docker compose up -d --build
docker compose logs -f
```

Файл `.env` остаётся на хосте и не попадает в образ. Заявки сохраняются в том `bot-data`.

## Структура проекта

```text
bot.py                 # точка входа и запуск LongPoll
config.py              # чтение .env и инициализация API
services.py            # каталог услуг для меню и системного промта ИИ
keyboards.py           # клавиатуры ВКонтакте
ai.py                  # клиент к LLM и хранение контекста диалога
handlers/              # обработчики приветствия, меню, заявок и ИИ-чата
docs/                  # справочная документация по архитектуре vkbottle
Dockerfile             # сборка контейнера
docker-compose.yml     # конфигурация запуска и томов
EnvExample             # шаблон переменных окружения
```
